Carregar meus dados do servidor

1. No servidor, gere os dois arquivos. O comando instala o jq, que remove os logs brutos de cada alerta para o arquivo ficar leve.

sudo apt install -y jq && sudo cscli alerts list -o json --since 30d -l 0 | jq '(. // []) | map(. + {domains: ([.events[]? | .meta[]? | select(.key=="target_fqdn") | .value] | group_by(.) | map({d: .[0], n: length}))} | del(.events))' > ~/alertas.json && sudo cscli decisions list -o json > ~/decisoes.json

2. Mostre o conteúdo dos arquivos e copie a saída, ou baixe os dois arquivos para este computador.

cat ~/alertas.json ~/decisoes.json

3a. Cole a saída aqui.

3b. Ou selecione os arquivos.

Tudo é lido só no seu navegador. Nada é enviado para fora desta página.
